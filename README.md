# 捷運島 MRT ISLAND

新北市永平國民小學 ・ 六年級彈性學習課程（校訂）
上課用的互動畫面。一台電腦投影，學生用紙筆，派信使到前面看題目。

網址：`https://<你的帳號>.github.io/<repo 名稱>/`

---

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 全部的課程內容。單一檔案，不需要編譯 |

後端（存進度和照片）另外放在 Google Apps Script，不在這個 repo 裡。

---

## 要更新內容時

1. 在 GitHub 這個 repo 的首頁，點 `index.html`
2. 右上角鉛筆圖示旁邊的 `...` → **Delete file** → Commit
   （或直接在檔案列表拖曳新檔案覆蓋）
3. 回到 repo 首頁 → **Add file** → **Upload files** → 把新的 `index.html` 拖進去
4. 最下面 **Commit changes**
5. 等一到兩分鐘，重新整理網頁就是新版

> 瀏覽器可能會快取舊版。看不到更新的話按 `Ctrl + Shift + R`（Mac 是 `Cmd + Shift + R`）強制重新整理。

---

## 第一次在新裝置上使用

開啟網址後：

1. 右下角 **教師控制臺**
2. 找到 **雲端同步**
3. 填入兩格：
   - Apps Script 的 `/exec` 網址
   - 通關密語（和後端程式裡 `var KEY` 設的那一串一樣）
4. 按 **儲存並連線**，右上角出現「已同步」

設定會記在那台裝置的瀏覽器裡，之後不用再填。

## 注意

- 這個網址是公開的，**不要把學生姓名、座號或照片放進這個 repo**
- 學生的任務紙照片是存到老師自己的 Google 雲端硬碟，不在這裡
